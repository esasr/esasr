# Lordicon illustration

`puzzle.json` is the puzzle illustration distributed in Lordicon's official
player examples: https://github.com/lordicondev/player-element/tree/main/examples/icons

Source: https://raw.githubusercontent.com/lordicondev/player-element/main/examples/icons/puzzle.json
Retrieved 2026-10-13. The repository's MIT notice is retained as LICENSE.txt.
Additional attribution is visible on the site's About page (Icons by Lordicon).
This asset is used as an interface illustration, not as the ESASR logo.

The player is dynamically imported from `@lordicon/element`; the JSON is served
locally. No third-party runtime CDN, API key, tracking call or paid icon is needed.
