# ESASR ScholarGym 离线基线评测

日期：2026-08-21
状态：完成
性质：开发基线，不作为 ScholarGym 官方排行榜成绩

## 实验设置

- 静态语料：ScholarGym 570,206 篇论文。
- 查询集：从 2,458 条含正样本查询中按来源占比分层抽取 200 条，随机种子为 2026。
- 样本构成：PASA AutoScholar 156 条、PASA RealScholar 4 条、LitSearch 40 条。
- 检索器：SQLite FTS5 BM25 兼容排序，标题权重 5、摘要权重 1。
- 时间约束：只保留不晚于查询日期的论文。
- 预算：API 调用 0 次、LLM 调用 0 次、Token 0。
- 评测：Macro Precision、Recall、F1、MAP、MRR、nDCG；F1 使用 1,000 次 bootstrap 计算 95% 置信区间。

## 结论与下一步

BM25 兼容词法检索在 Top-100 已召回 54.11% 的 Gold 论文，说明静态语料与指标链路可用；但候选数从 5 增至 100 时 Precision 明显下降，因此后续提升 F1 的关键不是继续无约束扩大候选集，而是加入查询分解、RRF 多查询融合和候选相关性筛选。下一轮应在相同语料、查询、随机种子和候选预算下比较：原始查询、规则查询扩展、ESASR 查询规划、RRF 融合及本地 Cross Encoder 精排。

本结果使用比例分层开发样本，不等同于论文中的 Test-Fast 固定划分，也不能与官方表格直接横向比较。
