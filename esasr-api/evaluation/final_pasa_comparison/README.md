# 决赛版受控对比归档

本目录记录 ESASR 与 PaSa 元数据/API 流程适配版的冻结协议和完整汇总。PaSa 上游版本、样本标识、代码及数据哈希均在 protocol.json 中，不包含凭据。固定随机 30 条查询重复 10 轮，共 600 次系统执行；独立统计单位为查询，配对聚类 Bootstrap 5,000 次。

核心资源收益：Token 减少 63.6%，LLM 请求减少 79.3%，逻辑检索调用减少 25.9%。完整质量、耗时及区间均保留在 summary.json。Macro F1@20 均值 0.1042 对 0.0636，配对差值区间跨零，报告为样本均值变化。端到端时间包含网络和上游服务；未扣除假定网络常量。两组各 185/300 次运行记录到上游异常，主要为 OpenAlex 限流，全部保留。

- protocol.json：抽样、调度、参数、源版本与哈希。
- summary.json：所有指标、配对差值 95% 区间及轮间标准差。
- 汇总指标.csv、逐轮指标.csv：对应可读汇总。

ESASR 在线配置：CPU MiniLM Cross-Encoder 前 80 篇；批量核验最多 24 篇；共享 DeepSeek、双学术源；缓存关闭；最多 8 次逻辑检索调用、20 篇最终输出。Token 来自 API usage，包含规划与核验。重复执行不是增加独立查询样本量。本目录是结果摘要归档，不是包含原始逐请求日志的完整复跑包。
